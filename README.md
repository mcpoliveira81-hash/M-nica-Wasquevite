# Mônica Wasquevite

Website institucional da **Dra. Mônica Wasquevite Reck — Dentista, CRO-RS 19033**, atendimento em Alegrete — RS.

> Da infância à vida adulta, cuidado em cada fase.

## Estrutura

- `index.html` — página única com todas as seções
- `styles.css` — identidade visual (bordô `#641F2A`, off-white `#F7F3EE`, bege `#E9DED4`)
- `script.js` — menu, header no scroll, animações de entrada e FAQ
- `favicon.svg` — ícone do site
- `monica-*.jpg` — fotos usadas no site (versões otimizadas)
- `serve.ps1` — servidor local para preview (`http://localhost:8787`)
- `prepare-images.ps1` — gera as versões otimizadas das fotos

## Preview local

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Abra `http://localhost:8787/`.
